# AI阅读助手 (Ureader)

一款对话驱动的AI阅读助手，帮助用户深入理解阅读内容，提供智能分析和个性化建议。

## 项目简介

AI阅读助手通过AI赋能提升阅读效率和理解深度，打造极简操作的阅读伴侣。解决阅读时理解困难、知识关联不足的问题，面向深度阅读者、学生、研究人员。

## 功能列表

### 🏗️ 核心基础功能

1. **多AI后端兼容** - 支持主流AI助手，默认Hermes
2. **对话历史管理** - 有效利用上下文记忆
3. **文本输入接口** - 用户可粘贴或输入要分析的文字

### 🎭 被动功能（用户触发）

当用户发送一段文字后，主动弹出快捷选项：

1. **内容总结** - 生成段落/章节摘要
2. **多语言翻译** - 支持多种语言互译
3. **深度解读** - 分析文本含义、背景、隐喻
4. **词汇提取** - 提取关键词、专业术语并解释
5. **概念图谱** - 快速分析相关、同类概念的关系与总体结构
6. **主题识别** - 识别文本核心主题
7. **情感分析** - 分析文本情感基调
8. **问答模式** - 用户针对文本提问，AI解答
9. **关键点梳理** - 列出核心要点

### 🚀 主动功能（AI驱动）

通过Skill后台收集信息，主动提供分析：

1. **微信阅读集成** - 同步阅读进度、标注
2. **阅读进度分析** - 分析阅读速度、习惯
3. **内容连贯性建议** - 提醒遗忘的前文要点
4. **相关知识扩展** - 主动提供背景资料
5. **阅读建议** - 基于阅读行为给出改进建议
6. **主题关联** - 连接不同章节的相关概念
7. **后续内容预测** - 基于前文推测后续发展
8. **阅读提醒** - 根据目标提醒继续阅读
9. **AI问答互动** - 根据对话历史和阅读划线，提出3-5个精选问题询问用户

### 🛠️ 对话增强功能

1. **上下文回顾** - 快速回顾之前的对话和分析
2. **多轮对话** - 针对同一文本深入探讨
3. **对话导出** - 导出分析记录和对话历史
4. **个性化设置** - 调整AI回复风格、详细程度
5. **快捷指令** - 自定义快捷短语触发常用功能
6. **历史记录** - 保存所有分析对话

### 📊 数据与统计

1. **阅读统计** - 阅读时长、进度、速度
2. **分析历史** - 所有AI分析的记录归档
3. **词汇本** - 积累学习的新词汇
4. **主题追踪** - 追踪阅读过的主题领域

## 技术栈

- **前端框架**: React 18 + TypeScript
- **移动框架**: Capacitor 5 (跨平台Android/iOS)
- **状态管理**: React Context + useReducer
- **路由**: React Router v6
- **样式**: Tailwind CSS
- **图表**: Recharts
- **概念图谱**: React Force Graph
- **存储**: Capacitor Storage (本地存储)
- **AI接口**: Hermes (默认)，支持多后端配置

## 开发环境

- Node.js 20+
- Android SDK 34
- Java 17+

## UI/UX设计

### 设计风格
- **主色调**: 深蓝 (#1e3a5f) + 柔和绿 (#2ecc71)
- **按钮风格**: 圆角胶囊形，轻微阴影，悬停上浮效果
- **字体**: 思源黑体 + Roboto
- **布局风格**: 卡片式聊天界面，底部固定输入栏
- **图标风格**: 简约线性图标，lucide-react风格

### 响应式设计
- 移动优先设计，适配各种安卓屏幕尺寸
- 触摸优化，按钮最小48dp，适合单手操作
- 支持横竖屏切换

## AI后端 - Hermes

应用默认连接到Hermes AI网关，参考文档：
https://hermes-agent.nousresearch.com/docs/zh-Hans/user-guide/messaging/weixin

Hermes是一个本地运行的AI网关服务，支持通过微信等平台进行消息交互。

## 快速开始

```bash
# 安装依赖
cd ai-reading-assistant
npm install

# 开发模式
npm run dev

# 构建
npm run build

# 初始化Capacitor
npm run build
npx cap add android

# 同步构建到Android
npx cap sync

# 打开Android Studio
npx cap open android
```
